# SOGA: CAD-free active visual inspection of specular parts

Code, data, trained models and robot logs for the article

> S. Sarveswaran and Rajesh Ranganathan, *"SOGA: CAD-free active visual inspection of specular parts with
> glare-complementary views, dependence-aware evidence fusion and a budget-masked pointer policy learned from
> real images"*, submitted to *Pattern Analysis and Applications*.

Repository: **https://github.com/Sarves1003/soga_repo**

A myCobot 280 JN arm with a wrist camera and an NVIDIA Jetson Nano inspects a polished hydraulic piston with two
wear rings and an O-ring for four defects (missing hex-end ring, missing open-end ring, missing O-ring, rust).
The repository contains everything needed to recompute every table value and figure of the article on a CPU in
about 8 minutes, without a robot, a GPU or any download beyond this repository.

---

## 1. Quick start (three commands)

```bash
git clone https://github.com/Sarves1003/soga_repo.git && cd soga_repo
python3 -m pip install -r requirements.txt     # numpy, scipy, scikit-learn, scikit-image, pandas, matplotlib, pillow
bash reproduce_all.sh                          # about 8 min on a laptop CPU
```

`reproduce_all.sh` rebuilds the NumPy bundles from the stored folders, runs every analysis in the order of the
article, writes the numbers to `results/*.json` and the figures to `figures/*.pdf`, and finally runs
`verify_numbers.py`, which compares 155 numbers with the values printed in the article. The last line must read

```
155 of 155 checks passed
```

Each line of the check names the table or section, the quantity, the value obtained and the value printed in
the article, for example

```
PASS  Table base       Frozen DINOv2 ViT-S/14 + linear (ours) image mean AUC   got     0.8014   article        0.8
PASS  Table quality    Holm p vs greedy_pred (x1e-4)                           got      3.662   article        3.7
PASS  Sect. live views two-feature rule correct (of 248)                       got        242   article        242
```

The output of every step is written to `logs/`. A single step can also be run on its own (Section 3) once
`python3 tools/npz_tool.py rebuild` has been run.

Tested with Python 3.13 on Linux (exact versions in `requirements-lock.txt`); Python 3.9 or newer with the
minimum versions in `requirements.txt` is sufficient. Nothing is downloaded at run time and every random
generator is seeded, so repeated runs give identical numbers.

| `figures/` | Article figures, regenerated by the scripts (except `fig_setup_cell.pdf`, a photograph of the cell) |
| `training/` | Training code: evidence model (`task_colab.py`, `task_model.py`), view-selection environment (`views.py`), pointer policy (`geo_attn.py`), REINFORCE training with a shared baseline (`train_views.py`) |

## 4. Data formats

**`data/task_crops/`** (bundle `data/task_crops.npz`)
* `X` (1664, 112, 112, 3) uint8 crops in OpenCV (BGR) channel order, also stored as `X_png/00000.png …` (same order; reverse the last axis for display)
* `y` (1664, 4): item labels (1 = defect present); `m` (1664, 4): visibility masks; the items in `items` are
  hex-end ring, open-end ring, O-ring and rust
* `placement` (1664,): placement index 0–18
* `k` (1664,): view index, `k = 25·level + cell`, with levels L0 straight, L1 straight-low, L2 −10°, L3 +10°
  and the cell on a 5×5 table grid in row-major order; `k = 100` is the survey image
* `frac`: visible fraction of the part
* per placement: `names`, `conditions`, `Yp`, `Mp` (part-level labels and masks), `poses`, `rust_facing`

**`data/task_oof/`**: `P` (1664, 4) out-of-fold item probabilities of the frozen DINOv2 ViT-S/14 with the masked
head (five folds grouped by placement), `fold` (1664,), `temperature` (4,). `data/task_oof_cnn/` holds the same
for the CNN trained from scratch.

**`data/view_library/`**: per placement (19) and view (100)
* measured patch qualities `Q` (19, 100, 25) and survey-predicted qualities `qpred`
* travel times `T` (19, 101, 100) in seconds (row 100 is the survey pose)
* availability after certification `avail`
* footprint fractions `fp_part`, `fp_edge`, `fp_glare`
* train/test `split`

`data/view_library_task/` adds the task evidence `Ptask` (19, 101, 4), `Ytask` and `Mtask`.

**Robot logs** (`data/live/hw_logs/*/<run>/`)
* `events.csv`: time-stamped state machine
* `moves.csv`: every commanded move, with target, certification result, refusal flag and timing
* captured images (`*.jpg`) and the fitted part model (`part_estimate.jpg`)
* unrolled surface and coverage maps (`*.png`)
* run summary (`soga_run.json`, `verdict.json`)

## 5. Retraining (optional, GPU recommended)

The analyses use the stored out-of-fold predictions and trained policies. To retrain them:

```bash
python3 -m pip install -r requirements-train.txt     # torch, opencv-python
cd training
# evidence model: frozen DINOv2 ViT-S/14 (torch.hub) + masked multi-label head, five folds grouped by placement
python3 task_colab.py classify --crops ../data/task_crops.npz --backbone vit
python3 task_colab.py classify --crops ../data/task_crops.npz --backbone cnn --suffix _cnn    # CNN baseline
python3 task_colab.py library  --library ../data/view_library.npz                           # task evidence per view
# view-selection policy, quality reward (72-77 min on an RTX 3050)
python3 train_views.py --data ../data/view_library.npz --arch attn --seed 0
# task-reward variants
python3 train_views.py --data ../data/view_library_task.npz --arch attn --seed 0
python3 train_views.py --data ../data/view_library_task.npz --arch mlp  --seed 0
python3 train_views.py --data ../data/view_library_task.npz --arch attn --seed 0 --no-time
```

Weights are written to `training/deploy/` and logs to `training/results_views/` and `training/results_task/`.
Copy them to `models/` and `results/` to rerun the analyses on them. The DINOv2 weights are downloaded by
`torch.hub` on first use (`facebookresearch/dinov2`, `dinov2_vits14`).

## 6. Running on the robot

Hardware: myCobot 280 JN (Elephant Robotics), NVIDIA Jetson Nano 4 GB, 640×480 USB camera on the flange, ArUco
markers on the table. Software on the Jetson: Python 3.6 or newer, `numpy`, `opencv-python`, `pymycobot`.

* `framework/RUNBOOK_FINAL.md`: collecting the view library and the training data, live evaluation
* `framework/RUNBOOK_AUTONOMOUS.md`: SOGA against the other strategies on the robot (`framework/soga.py`) and
  autonomous inspection (`framework/autoinspect.py`)
* `framework/RUNBOOK_MOTION.md`: motion and timing study

Every move is certified before motion (single inverse-kinematics branch, conditioning of the scaled Jacobian,
joint margins, workspace fence) and verified after motion by registering the image to the survey.
